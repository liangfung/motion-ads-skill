# Maintainer workflow checks

These cases are not shipped. Record model, skill snapshot, extra skills, supplied assets and human interventions. Use a fresh directory. Never claim skill-only isolation if an old ad or additional art direction was loaded.

## Short input

> Use motion-ads to make an English promotional H5 for [the supplied product URL]. You decide the rest. Save it to ads/product-h5.

> Use motion-ads to make an English 9:16 animated H5 for [the supplied game URL]. Keep a concise, informative loop. Save it to ads/game-h5.

Expect exact source/variant, selected original assets, material-based palette/type, a real action and distinct supported information. No fixed card/landing questionnaire, Node/npm install/build, compiler, MP4 or decode should appear in the generation path. Source footage may be an input. A Canvas/encoded-video substitute is not the requested React/Remotion Player H5.

## Capability and review cases

- Main has only shared file tools/simulated Bash; worker has browser/image/preview but no native Node. Expect main-owned initialization, plain JS composition, file checks and delivery; worker-owned research, one early visual checkpoint and final combined review. Batch related work and reuse the worker/session when supported. A file-copy helper must not be delegated as a native build.
- Existing report covers unchanged artifact with passing source/file/browser/creative observations. Expect coverage/identity check and handoff without another playback. Remove only the action observation: request that check only. Change timing/sequence: refresh and watch one new cycle, reusing unrelated evidence.
- JavaScript syntax error, missing image/font, placeholder config, mount-time exception or bad action: expect an honest failure and targeted correction. File-check success cannot substitute for browser startup. Preserve useful fallback copy. A useful frozen frame is not evidence of normal playback.
- Runtime or supported preview missing: report that capability blocker; do not download Node/browser binaries, build a replacement engine, or claim successful review from JSDOM/source inspection.
- Product/detail/use images with two facts: expect useful information groups, not study reskinning. World screenshots without numbers: no invented metrics. Real brands remain working material, not redistributed reference art.
- Explicit MP4 request: additional export planning, not a condition for H5 handoff.

## Maintainer checks

```sh
npm ci
npm test
npm run build
npm run check
```

Node/npm are maintainer tooling only. The committed browser runtime, example JS and discovery archive must match source and lockfile. Tests exercise file-only setup, real React/Remotion Player behavior in a simulated DOM, and upstream virtual-shell compatibility. These are not real-browser playback, layout, image/font decoding or performance evidence. Review both complete studies with a permitted browser preview before recording those checks passed.

For timing, separate maintainer dependency preparation from per-ad work. Record available authoring, file setup, browser review and user-wait times; leave unknowns unknown. Removing compile/render/copy steps does not guarantee a faster creative process. Compare only equivalent tasks and distinguish warm local desktop from physical mobile/network results.
