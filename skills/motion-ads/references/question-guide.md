# Question guide

Research first; ask only when the answer changes the result, in the user's language. Use the host's clarification tool or the conversation. There is no fixed questionnaire or mandatory approval round. Skip decisions already supplied or delegated; state reasonable assumptions and proceed with supported material.

## Decisions worth clarifying

| Area | Ask when | Useful choices |
|---|---|---|
| Placement | Unknown size, embedding restriction or reading context materially changes layout | Supplied dimensions; compact portrait loop; a wider composition; useful scrolling detail |
| Product/story | Multiple variants, conflicting claims or unusable assets block the argument | Confirm variant; omit uncertain detail; supply an original asset |
| Audience/action | Different goals imply different evidence and copy | Shop; explore; install; wishlist; a real demo destination |
| Visual direction | Material leaves meaningfully different plausible directions | Two or three source-aware options with a recommendation |
| Motion source | Gameplay/footage is requested but only stills exist | Honest artwork animation; approved video; locate official footage |
| Destination | No actual URL or the supplied URL conflicts with the action | Source URL, supplied campaign URL, a real in-page target |
| Language | Source, audience and requested language conflict | Resolve intended audience language |

Do not ask the user to choose a technical category such as card versus landing before making an H5. Choose a canvas and ordinary HTML flow from the intended placement. Do not add scrolling, selectors or a quiz merely because they are possible. Missing optional price, offers, ratings or testimonials usually calls for omission, not a question.

## Ask with context

Briefly state the identified subject/variant, core promise, two or three useful facts, selected asset roles and proposed action. Mention only uncertainties that affect truth or design. A URL normally supplies the default destination; preserve intentional campaign parameters. If timing has no placement limit, propose a concise loop with readable holds rather than asking for an arbitrary number.

An unresolved question might be: “The selected material supports either a quiet detail study or a bright use-context story. I recommend the latter for this audience; which direction fits your campaign?” Do not ask the user to re-verify every scraped field.

## After feedback

Apply specific edits in the existing project. Ask a focused question only when a subjective request has materially different interpretations. Keep source, research and unchanged acceptance evidence; do not restart the workflow for a small revision.
